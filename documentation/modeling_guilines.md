* Use prefixes:
    * v for variables: vStartTime
    * p for parameters
    * c for constaints
    * fc for rules that define constraints
* Use self-explanatory names but try to keep them short. You do not need to use the same name used in the formulation.
* Define all the rules first and below activate them
* Use the same name for the rule and for the constraint (but for the prefix)
